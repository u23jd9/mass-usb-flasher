## Часть 1. Обзор проекта

### Назначение
Кроссплатформенная консольная утилита (TUI) для массовой прошивки USB-накопителей одним образом. Коммерческое применение: прошивка партий флешек (обычно 5+ одновременно). Критичны надёжность, верификация и логирование.

### Текущая версия
`0.1.1` — стабильно работающая, базовая функциональность.

### Что работает

| Функция | Windows | Linux |
|---|---|---|
| TUI (ratatui) | ✅ | ✅ |
| Обнаружение USB-устройств | ✅ | ✅ |
| Параллельная запись 5+ устройств | ✅ | ✅ |
| SHA-256 образа с прогрессом | ✅ | ✅ |
| Каталог образов (work names) | ✅ | ✅ |
| Импорт папки с манифестом `.muf-images.json` | ✅ | ✅ |
| Прогресс в taskbar | ✅ (ITaskbarList3) | ❌ (нет аналога) |
| Заголовок окна с прогрессом | ✅ | ✅ |
| Переключение языка EN/RU | ✅ | ✅ |
| Правка `target_count` через TUI | ✅ | ✅ |
| UAC elevation | ✅ (manifest) | ✅ (через sudo) |
| Обход `ACCESS_DENIED` (offline-диск) | ✅ | N/A |

### Что НЕ реализовано (TODO для следующего агента)

1. **Верификация после записи** (перечитать флешку и сравнить SHA-256 с образом).
2. **Форматирование** (переинициализация флешек: FAT32/exFAT/NTFS/ext4).
3. **Последовательная запись** (concurrency=1: сначала одна флешка, потом вторая — для дешёвых кард-ридеров, которые перегреваются).
4. **JSONL-логирование** для аудита коммерческих партий.
5. **Асинхронный движок** (`async_writer.rs`) — был написан экспериментально, но стабильность не подтверждена, оставлен `bus_writer`.
6. **GUI** (задача, которую решит следующий агент).

### Ключевые решения

- **`bus_writer`** от System76 — lock-free broadcast: образ читается один раз, блоки рассылаются всем writer'ам одновременно. Проверен, стабилен.
- **Один читатель — N писателей** — критично для производительности (не N раз читаем образ).
- **`O_SYNC` на Linux вместо `O_DIRECT`** — `O_DIRECT` требует выровненных буферов, а `bus_writer` их не гарантирует. `O_SYNC` медленнее на ~10–15%, но стабилен.
- **`FILE_FLAG_NO_BUFFERING` на Windows** без `WRITE_THROUGH` — `WRITE_THROUGH` замедляет запись в 2–5 раз (запись ждёт подтверждения от носителя после каждой операции).
- **Offline-диск на Windows** (`IOCTL_DISK_SET_DISK_ATTRIBUTES`) — обход `ACCESS_DENIED` при записи на `\\.\PhysicalDriveN` с активными томами.
- **`FindFirstVolumeW`** вместо перебора `A:..Z:` — перебор пропускал безбуквенные тома (EFI, recovery).

**Требования:** Rust (MSVC toolchain), Visual Studio Build Tools (Desktop C++ + Windows SDK).

```powershell
cargo build --release
# Готовый бинарник: target\release\muf.exe
```

**Опционально** — `.cargo/config.toml` для статической линковки CRT (без VC++ Redistributable):
```toml
[target.x86_64-pc-windows-msvc]
rustflags = ["-C", "target-feature=+crt-static"]
```

### Linux (Fedora 40+)

**Требования:**
```bash
sudo dnf install -y rust cargo gcc pkgconf-pkg-config \
    wayland-devel wayland-protocols-devel libxkbcommon-devel \
    systemd-devel dbus-devel glib2-devel
```

**Сборка:**
```bash
cargo build --release
sudo ./target/release/muf
```

**Почему `sudo`:** открытие `/dev/sdX` и `SCHED_FIFO` требуют root или `CAP_SYS_RAWIO`/`CAP_SYS_NICE`.

## Часть 4. История разработки (что было и что стало)

**Шаг 1–5: Базовый каркас TUI.** ratatui + crossterm, обнаружение дисков через `IOCTL_STORAGE_QUERY_PROPERTY`, фильтр по `BusTypeUsb = 7`.

**Шаг 6–8: SHA-256 образа.** Крейт `sha2` + прогресс через `mpsc`. Первая ошибка: в `debug`-сборке хеширование 4 ГБ занимало минуты (в 20–50 раз медленнее PowerShell). Решение — `[profile.dev.package."*"] opt-level = 3`.

**Шаг 9: Движок параллельной записи.** Крейт `bus_writer`, `Vec<File>` — открытые `\\.\PhysicalDriveN`.

**Шаг 10: Первая проблема `ACCESS_DENIED`.** Windows блокировал запись, потому что тома считались «живыми». Решение в три шага:
1. `FindFirstVolumeW` вместо `A:..Z:` — пропускались безбуквенные тома.
2. `FSCTL_LOCK_VOLUME` + `FSCTL_DISMOUNT_VOLUME` с retry.
3. `IOCTL_DISK_SET_DISK_ATTRIBUTES` с `DISK_ATTRIBUTE_OFFLINE` — после этого запись гарантированно идёт. **Ключевой обход.**

**Шаг 11: Скорость.** Убран `FILE_FLAG_WRITE_THROUGH` — запись ускорилась в 2–5 раз. Буфер `BufReader` увеличен с 1 до 8 МБ.

**Шаг 12: UI-метрики.** `Elapsed`, `Speed per device`, `Written` (среднее по активным, не сумма!), taskbar, заголовок окна.

**Шаг 13: Русская раскладка.** `normalize_key()` — маппинг ЙЦУКЕН → QWERTY по позиции клавиши.

**Шаг 14: Двойной ввод.** `KeyEventKind::Press` фильтр — иначе `+/-` меняют target на ±2.

**Шаг 15: Каталог образов.** JSON-хранилище в `%USERPROFILE%\.muf\catalog.json`. Work names, SHA-256, импорт папки с манифестом `.muf-images.json`.

**Шаг 16: Порт на Linux.** `device/linux.rs` — `/sys/block` для обнаружения, `umount2(MNT_DETACH)` для размонтирования, `O_SYNC` (не `O_DIRECT`) для записи.

**Что не сработало:**
- **`O_DIRECT` на Linux** → `EINVAL` (os error 22): `bus_writer` использует невыровненные буферы. Отказались, используем `O_SYNC`.
- **`async_writer`** (overlapped I/O на Windows) — дал прирост только в первую минуту, затем замедление из-за перегрева контроллера. Разница 1–2 мин на партию — не критично. Оставлен `bus_writer`.
- **`FILE_FLAG_WRITE_THROUGH`** — замедлял в разы, убран.
- **Перебор `A:..Z:`** — пропускал тома, заменён на `FindFirstVolumeW`.

**Что показало лучший результат:**
- **`FindFirstVolumeW` + offline-диск** — решило `ACCESS_DENIED` полностью.
- **Последовательная запись** (планируется как concurrency=1 по умолчанию) — устраняет перегрев дешёвых кард-ридеров и ошибку 433 (`ERROR_NO_SUCH_DEVICE`). На одной флешке — 38.7 МБ/с, на двух одновременно — падает до ~19 МБ/с на каждую и одна отваливается.

### 📄 `src/main.rs` (общий, с cfg-блоками)

```rust
#![allow(dead_code)]

mod app;
mod catalog;
mod device;
mod engine;
mod i18n;
mod image;
mod taskbar;
mod ui;

use std::io::{self, Stdout};
use std::path::PathBuf;
use std::sync::mpsc::{channel, Receiver, TryRecvError};
use std::thread;
use std::time::{Duration, Instant};

use ratatui::{
    backend::CrosstermBackend,
    crossterm::{
        event::{self, Event, KeyCode, KeyEvent, KeyEventKind, KeyModifiers},
        execute,
        terminal::{
            disable_raw_mode, enable_raw_mode, EnterAlternateScreen, LeaveAlternateScreen, SetTitle,
        },
    },
    Terminal,
};

use app::{AppState, AppStatus, HashJob, Screen, SlotStatus};
use catalog::{spawn_folder_import, unix_now, ImageEntry, ImportProgress};
use device::watcher::{DeviceFilter, WatcherConfig, WatcherHandle};
use engine::writer::{start_write, WriteEvent};
use i18n::{VERSION, WATERMARK, WATERMARK_URL};
use image::{compute_sha256_async, HashProgress};
use taskbar::Taskbar;

pub enum PrepareResult {
    Log(String),
    Ready {
        write_rx: Receiver<WriteEvent>,
        opened_numbers: Vec<u32>,
        files_count: usize,
    },
    Failed(String),
}

fn main() -> io::Result<()> {
    install_panic_hook();

    if !device::is_admin() {
        eprintln!("[!] Administrator/root privileges required. Run as administrator (Windows) or with sudo (Linux).");
        std::process::exit(1);
    }

    enable_raw_mode()?;
    let mut stdout = io::stdout();
    execute!(stdout, EnterAlternateScreen)?;
    let backend = CrosstermBackend::new(stdout);
    let mut terminal = Terminal::new(backend)?;

    let res = run(&mut terminal);

    let _ = disable_raw_mode();
    let _ = execute!(terminal.backend_mut(), LeaveAlternateScreen);
    let _ = terminal.show_cursor();

    if let Ok(state) = &res {
        print_final_log(state);
    }

    print_watermark_clickable();

    res.map(|_| ())
}

fn print_final_log(state: &AppState) {
    println!("\n=== Final log ({} lines, last 40) ===", state.log.len());
    for line in state.log.iter().rev().take(40).collect::<Vec<_>>().iter().rev() {
        println!("{}", line);
    }
}

fn print_watermark_clickable() {
    println!();
    println!(
        "\x1b]8;;{}\x1b\\{}\x1b]8;;\x1b\\  ·  Mass USB Flasher v{}",
        WATERMARK_URL, WATERMARK, VERSION
    );
    println!(
        "Link: \x1b]8;;{}\x1b\\{}\x1b]8;;\x1b\\",
        WATERMARK_URL, WATERMARK_URL
    );
}

fn install_panic_hook() {
    let original = std::panic::take_hook();
    std::panic::set_hook(Box::new(move |info| {
        let _ = disable_raw_mode();
        let _ = execute!(io::stdout(), LeaveAlternateScreen);
        original(info);
    }));
}

fn run(terminal: &mut Terminal<CrosstermBackend<Stdout>>) -> io::Result<AppState> {
    let mut state = AppState::new();

    if let Some(n) = parse_target_count_arg() {
        state.set_target_count(n);
    }

    #[cfg(windows)]
    match ensure_automount_enabled() {
        Ok(()) => state.push_log("mountvol /e — automount enabled"),
        Err(e) => state.push_log(format!("[!] mountvol /e failed: {}", e)),
    }

    #[cfg(target_os = "linux")]
    state.push_log("Running on Linux");

    state.catalog = catalog::Catalog::load_or_default(&state.catalog_path);
    state.push_log(format!(
        "Catalog loaded: {} entries ({})",
        state.catalog.images.len(),
        state.catalog_path.display()
    ));

    let filter = DeviceFilter {
        usb_only: true,
        min_size_bytes: 4 * 1024 * 1024 * 1024,
        max_size_bytes: 128 * 1024 * 1024 * 1024,
    };
    let handle = device::watcher::spawn(WatcherConfig {
        poll_interval: Duration::from_millis(500),
        max_disks: 16,
        filter,
    });

    if let Some(path) = parse_args() {
        load_image_from_cli(&mut state, path);
    }

    let taskbar = Taskbar::new();
    let _ = set_window_title(&state);

    let mut last_title = String::new();
    let mut last_taskbar_update = Instant::now();
    let mut last_taskbar_pct: i32 = -1;

    loop {
        drain_device_events(&mut state, &handle);
        drain_hash_job(&mut state);
        drain_import_job(&mut state);
        drain_prepare(&mut state);
        drain_write(&mut state);

        terminal.draw(|f| ui::render(f, &state))?;

        let new_title = compute_window_title(&state);
        if new_title != last_title {
            let mut out = io::stdout();
            let _ = execute!(out, SetTitle(&new_title));
            last_title = new_title;
        }

        if last_taskbar_update.elapsed() >= Duration::from_millis(100) {
            let total = state.write_total_bytes;
            let done = state.slowest_bytes_written();
            if total > 0 && matches!(state.status, AppStatus::Running) {
                let pct = ((done as f64 / total as f64) * 100.0)
                    .clamp(0.0, 100.0)
                    .round() as i32;
                if pct != last_taskbar_pct {
                    taskbar.set(done, total);
                    last_taskbar_pct = pct;
                }
            } else if last_taskbar_pct >= 0 {
                taskbar.clear();
                last_taskbar_pct = -1;
            }
            last_taskbar_update = Instant::now();
        }

        if event::poll(Duration::from_millis(100))? {
            if let Event::Key(key) = event::read()? {
                if handle_key(&mut state, key) {
                    break;
                }
            }
        }

        auto_transition_finished(&mut state);
    }

    taskbar.clear();
    Ok(state)
}

#[cfg(windows)]
fn ensure_automount_enabled() -> Result<(), String> {
    use std::process::Command;
    let output = Command::new("cmd")
        .args(["/C", "mountvol", "/e"])
        .output()
        .map_err(|e| format!("failed to run mountvol: {}", e))?;
    if !output.status.success() {
        return Err(format!(
            "code {:?}, stderr: {}",
            output.status.code(),
            String::from_utf8_lossy(&output.stderr).trim()
        ));
    }
    Ok(())
}

fn set_window_title(state: &AppState) -> io::Result<()> {
    let title = compute_window_title(state);
    let mut out = io::stdout();
    execute!(out, SetTitle(&title))?;
    Ok(())
}

fn compute_window_title(state: &AppState) -> String {
    let status = match state.status {
        AppStatus::Idle => "Idle",
        AppStatus::WaitingForDevices => "Waiting",
        AppStatus::Ready => "Ready",
        AppStatus::Running => "Running",
        AppStatus::Finished => "Finished",
    };
    let target = state.target_count;
    let active = state.active_or_ready_count();

    if state.status == AppStatus::Running && state.write_total_bytes > 0 {
        let done = state.slowest_bytes_written();
        let total = state.write_total_bytes;
        let pct = ((done as f64 / total as f64) * 100.0).clamp(0.0, 100.0).round() as u32;
        format!("Mass USB Flasher v{} — {} {}%", VERSION, status, pct)
    } else {
        format!("Mass USB Flasher v{} — {} [{}/{}]", VERSION, status, active, target)
    }
}

// --- Каналы ---

fn drain_device_events(state: &mut AppState, handle: &WatcherHandle) {
    while let Ok(ev) = handle.events.try_recv() {
        state.apply_device_event(ev);
    }
}

fn drain_hash_job(state: &mut AppState) {
    let Some(job) = state.hash_job.take() else { return; };
    let mut keep = true;
    loop {
        match job.rx.try_recv() {
            Ok(HashProgress::Progress { bytes_done, bytes_total }) => {
                state.image_hash_progress = Some((bytes_done, bytes_total));
            }
            Ok(HashProgress::Done { size_bytes, sha256 }) => {
                state.image_sha256 = Some(sha256.clone());
                state.image_hash_progress = None;
                state.push_log(format!("SHA-256: {}", sha256));
                if job.save_to_catalog {
                    save_current_image_to_catalog(state, size_bytes, sha256);
                }
                keep = false;
                break;
            }
            Ok(HashProgress::Error(e)) => {
                state.push_log(format!("[!] Image read error: {}", e));
                state.image_hash_progress = None;
                keep = false;
                break;
            }
            Err(TryRecvError::Empty) => break,
            Err(TryRecvError::Disconnected) => { keep = false; break; }
        }
    }
    if keep { state.hash_job = Some(job); }
}

fn save_current_image_to_catalog(state: &mut AppState, size_bytes: u64, sha256: String) {
    let (Some(work_name), Some(path)) = (state.image_work_name.clone(), state.image_path.clone()) else {
        return;
    };
    state.catalog.upsert(ImageEntry {
        work_name, path, size_bytes, sha256, added_at_unix: unix_now(),
    });
    match state.catalog.save(&state.catalog_path) {
        Ok(()) => state.push_log("Image added to catalog"),
        Err(e) => state.push_log(format!("[!] Catalog save failed: {}", e)),
    }
}

fn drain_import_job(state: &mut AppState) {
    let Some(rx) = state.import_job.take() else { return; };
    let mut keep = true;
    loop {
        match rx.try_recv() {
            Ok(p @ ImportProgress::Scanning { total }) => {
                state.push_log(format!("[import] scanning, files: {}", total));
                state.import_progress = Some(p);
            }
            Ok(p @ ImportProgress::HashingFile { .. }) => { state.import_progress = Some(p); }
            Ok(ImportProgress::FileDone { name }) => { state.push_log(format!("[import] {}", name)); }
            Ok(ImportProgress::Done { imported, entries }) => {
                state.push_log(format!("[import] done, imported: {}", imported));
                for e in entries { state.catalog.upsert(e); }
                match state.catalog.save(&state.catalog_path) {
                    Ok(()) => state.push_log("Catalog updated"),
                    Err(e) => state.push_log(format!("[!] Catalog: {}", e)),
                }
                state.import_progress = None;
                keep = false;
                break;
            }
            Ok(ImportProgress::Error(e)) => {
                state.push_log(format!("[!] Import: {}", e));
                state.import_progress = None;
                keep = false;
                break;
            }
            Err(TryRecvError::Empty) => break,
            Err(TryRecvError::Disconnected) => { state.import_progress = None; keep = false; break; }
        }
    }
    if keep { state.import_job = Some(rx); }
}

fn drain_prepare(state: &mut AppState) {
    let Some(rx) = state.prepare_rx.take() else { return; };
    let mut keep = true;
    loop {
        match rx.try_recv() {
            Ok(PrepareResult::Log(msg)) => state.push_log(msg),
            Ok(PrepareResult::Ready { write_rx, opened_numbers, files_count }) => {
                state.mark_slots_writing(&opened_numbers);
                state.write_started_at = Some(Instant::now());
                state.push_log(format!("=== Writing to {} devices ===", files_count));
                state.write_rx = Some(write_rx);
                keep = false;
                break;
            }
            Ok(PrepareResult::Failed(e)) => {
                state.push_log(format!("[!] Prepare failed: {}", e));
                state.status = AppStatus::Ready;
                state.write_started_at = None;
                state.rollback_slots_to_ready();
                keep = false;
                break;
            }
            Err(TryRecvError::Empty) => break,
            Err(TryRecvError::Disconnected) => { keep = false; break; }
        }
    }
    if keep { state.prepare_rx = Some(rx); }
}

fn drain_write(state: &mut AppState) {
    let Some(rx) = state.write_rx.take() else { return; };
    let mut keep = true;
    loop {
        match rx.try_recv() {
            Ok(WriteEvent::Progress { id, bytes_written }) => {
                state.update_progress_by_index(id, bytes_written, state.write_total_bytes);
            }
            Ok(WriteEvent::Completed { id }) => {
                state.mark_completed_by_index(id);
                state.push_log(format!("[{}] write complete", id));
            }
            Ok(WriteEvent::Errored { id, message }) => {
                state.mark_failed_by_index(id, message.clone());
                state.push_log(format!("[!] [{}] error: {}", id, message));
            }
            Ok(WriteEvent::Finished { result }) => {
                match result {
                    Ok(()) => state.push_log("=== Write complete ==="),
                    Err(e) => state.push_log(format!("[!] Write finished with error: {}", e)),
                }
                return_devices_online(state);
                state.status = AppStatus::Finished;
                keep = false;
                break;
            }
            Err(TryRecvError::Empty) => break,
            Err(TryRecvError::Disconnected) => {
                state.push_log("[!] Write channel disconnected");
                state.status = AppStatus::Finished;
                keep = false;
                break;
            }
        }
    }
    if keep { state.write_rx = Some(rx); }
}

fn return_devices_online(state: &mut AppState) {
    let numbers: Vec<u32> = state.devices.keys().copied().collect();
    for n in numbers {
        match engine::set_disk_offline(n, false) {
            Ok(()) => state.push_log(format!("[#{}] back online", n)),
            Err(e) => state.push_log(format!("[#{}] failed to bring online: {}", n, e)),
        }
    }
}

fn auto_transition_finished(state: &mut AppState) {
    if state.status != AppStatus::Running || state.devices.is_empty() { return; }
    let all_done = state.devices.values()
        .all(|s| matches!(s.status, SlotStatus::Done | SlotStatus::Failed));
    if all_done { state.status = AppStatus::Finished; }
}

fn handle_key(state: &mut AppState, key: KeyEvent) -> bool {
    if key.kind != KeyEventKind::Press { return false; }
    if key.modifiers.contains(KeyModifiers::CONTROL) {
        if matches!(key.code,
            KeyCode::Char('c') | KeyCode::Char('C') | KeyCode::Char('с') | KeyCode::Char('С')
        ) { return true; }
    }
    match state.screen {
        Screen::Main => handle_key_main(state, key),
        Screen::ImageSelect => handle_key_image_select(state, key),
        Screen::AddImageName => handle_key_add_name(state, key),
        Screen::RenameImage => handle_key_rename(state, key),
        Screen::Help => handle_key_help(state, key),
    }
}

fn handle_key_main(state: &mut AppState, key: KeyEvent) -> bool {
    match key.code {
        KeyCode::Char('+') | KeyCode::Char('=') => {
            state.increase_target();
            state.push_log(format!("Target: {}", state.target_count));
            return false;
        }
        KeyCode::Char('-') => {
            state.decrease_target();
            state.push_log(format!("Target: {}", state.target_count));
            return false;
        }
        _ => {}
    }
    let KeyCode::Char(c) = key.code else { return false; };
    match normalize_key(c) {
        'q' => return true,
        's' => start_write_flow(state),
        'i' => {
            state.screen = Screen::ImageSelect;
            state.image_select_index = 0;
            state.pending_image_path = None;
            state.push_log("Image catalog opened");
        }
        'h' => { state.screen = Screen::Help; }
        'l' => {
            state.lang = state.lang.toggle();
            state.push_log(format!("Language: {}", state.lang.code()));
        }
        'v' => state.push_log("Verify (stub)"),
        'r' => state.push_log("Reformat (stub)"),
        _ => {}
    }
    false
}

fn handle_key_image_select(state: &mut AppState, key: KeyEvent) -> bool {
    match key.code {
        KeyCode::Esc => { state.screen = Screen::Main; }
        KeyCode::Up => {
            state.image_select_index = state.image_select_index.saturating_sub(1);
        }
        KeyCode::Down => {
            let n = state.catalog.images.len();
            if n > 0 && state.image_select_index + 1 < n {
                state.image_select_index += 1;
            }
        }
        KeyCode::Enter => {
            let idx = state.image_select_index;
            if idx < state.catalog.images.len() {
                match state.select_image_from_catalog(idx) {
                    Ok(()) => {
                        let name = state.image_work_name.clone().unwrap_or_default();
                        state.push_log(format!("Selected: {}", name));
                        state.screen = Screen::Main;
                    }
                    Err(e) => state.push_log(format!("[!] {}", e)),
                }
            }
        }
        KeyCode::Char(c) => match normalize_key(c) {
            'a' => open_add_file_dialog(state),
            'o' => open_ephemeral_file_dialog(state),
            'd' => delete_selected_from_catalog(state),
            'r' => start_rename_selected(state),
            'f' => open_import_folder_dialog(state),
            _ => {}
        },
        _ => {}
    }
    false
}

fn handle_key_help(state: &mut AppState, key: KeyEvent) -> bool {
    match key.code {
        KeyCode::Char(_) | KeyCode::Esc | KeyCode::Enter => { state.screen = Screen::Main; }
        _ => {}
    }
    false
}

fn handle_key_add_name(state: &mut AppState, key: KeyEvent) -> bool {

}

        KeyCode::Enter => commit_rename(state),
        KeyCode::Backspace => { state.input_buffer.pop(); }
        KeyCode::Char(c) => push_name_char(state, c),
        _ => {}

}

    }

fn delete_selected_from_catalog(state: &mut AppState) {
    let idx = state.image_select_index;

            state.image_select_index -= 1;

    state.screen = Screen::RenameImage;

fn commit_rename(state: &mut AppState) {
    let new_name = state.input_buffer.trim().to_string();
    if new_name.is_empty() { return; }
    let Some(idx) = state.rename_target_index.take() else { return; };
    let Some(old_name) = state.catalog.images.get(idx).map(|e| e.work_name.clone())
        else { state.screen = Screen::ImageSelect; return; };
    match state.rename_in_catalog(&old_name, &new_name) {
        Ok(()) => {
            match state.catalog.save(&state.catalog_path) {
                Ok(()) => state.push_log(format!("Renamed '{}' → '{}'", old_name, new_name)),
                Err(e) => state.push_log(format!("[!] Catalog: {}", e)),
            }
            state.screen = Screen::ImageSelect;
        }
        Err(e) => {
            state.push_log(format!("[!] {}", e));
            state.rename_target_index = Some(idx);
        }
    }
    state.input_buffer.clear();
}

fn commit_new_image(state: &mut AppState) {
    let work_name = state.input_buffer.trim().to_string();

    state.image_work_name = Some(work_name.clone());
    state.image_sha256 = None;
    state.image_hash_progress = None;
    state.push_log(format!("Computing SHA-256 for '{}'…", work_name));
    state.hash_job = Some(HashJob {
        rx: compute_sha256_async(path.display().to_string()),
        save_to_catalog: true,

    state.screen = Screen::Main;
    state.input_buffer.clear();

        rx: compute_sha256_async(path.display().to_string()),
        save_to_catalog: false,
    });
}

fn start_write_flow(state: &mut AppState) {
    if state.image_path.is_none() {
        state.push_log("[!] Select an image first (I)");
        return;
    }
    if state.image_sha256.is_none() {
        state.push_log("[!] SHA-256 not yet computed");
        return;
    }
    let device_numbers = state.ready_device_numbers();
    if device_numbers.is_empty() {
        state.push_log("[!] No devices in Ready state");
        return;
    }
    if device_numbers.len() < state.target_count {
        state.push_log(format!("[!] Need {} devices, ready {}",
            state.target_count, device_numbers.len()));
        return;
    }
    if state.status == AppStatus::Running || state.prepare_rx.is_some() {
        state.push_log("[!] Operation already in progress");
        return;
    }

    let image_path = state.image_path.as_ref().unwrap().display().to_string();
    let total = state.image_size;
    state.status = AppStatus::Running;
    state.write_total_bytes = total;
    state.write_started_at = None;
    state.push_log(format!("Preparing {} devices…", device_numbers.len()));

    let (tx, rx) = channel();
    state.prepare_rx = Some(rx);
    thread::spawn(move || prepare_and_start(tx, device_numbers, image_path, total));
}

fn prepare_and_start(
    tx: std::sync::mpsc::Sender<PrepareResult>,
    device_numbers: Vec<u32>,
    image_path: String,
    total: u64,
) {
    let mut opened: Vec<(u32, std::fs::File)> = Vec::new();

    for n in device_numbers {
        let _ = tx.send(PrepareResult::Log(format!("[#{}] unmounting volumes…", n)));

        #[cfg(windows)]
        {
            match engine::unmount_all_volumes_on_disk(n) {
                Ok(0) => { let _ = tx.send(PrepareResult::Log(format!("[#{}] no volumes", n))); }
                Ok(c) => {
                    let _ = tx.send(PrepareResult::Log(format!(
                        "[#{}] volumes unmounted: {}", n, c)));
                }
                Err(e) => {
                    let _ = tx.send(PrepareResult::Log(format!(
                        "[#{}] unmount error: {}", n, e)));
                }
            }
            let _ = tx.send(PrepareResult::Log(format!("[#{}] setting offline…", n)));
            if let Err(e) = engine::set_disk_offline(n, true) {
                let _ = tx.send(PrepareResult::Log(format!(
                    "[!] #{} offline failed: {}", n, e)));
            }
        }

        #[cfg(target_os = "linux")]
        {
            match engine::unmount_all_volumes_on_disk(n) {
                Ok(0) => { let _ = tx.send(PrepareResult::Log(format!("[#{}] no mounts", n))); }
                Ok(c) => {
                    let _ = tx.send(PrepareResult::Log(format!(
                        "[#{}] unmounted: {}", n, c)));
                }
                Err(e) => {
                    let _ = tx.send(PrepareResult::Log(format!(
                        "[#{}] unmount error: {}", n, e)));
                }
            }
        }

        match engine::open_drive_write(n) {
            Ok(f) => {
                let _ = tx.send(PrepareResult::Log(format!("[#{}] opened for write", n)));
                opened.push((n, f));
            }
            Err(e) => {
                let _ = tx.send(PrepareResult::Log(format!(
                    "[!] #{} open failed: {}", n, e)));
            }
        }
    }

    if opened.is_empty() {
        let _ = tx.send(PrepareResult::Failed("no devices opened".into()));
        return;
    }

    let opened_numbers: Vec<u32> = opened.iter().map(|(n, _)| *n).collect();
    let files_count = opened.len();
    let files: Vec<std::fs::File> = opened.into_iter().map(|(_, f)| f).collect();
    let write_rx = start_write(image_path, files, total);
    let _ = tx.send(PrepareResult::Ready { write_rx, opened_numbers, files_count });
}

fn normalize_key(c: char) -> char {
    let lower = c.to_lowercase().next().unwrap_or(c);
    match lower {
        'й' => 'q', 'ц' => 'w', 'у' => 'e', 'к' => 'r', 'е' => 't', 'н' => 'y',
        'г' => 'u', 'ш' => 'i', 'щ' => 'o', 'з' => 'p', 'х' => '[', 'ъ' => ']',
        'ф' => 'a', 'ы' => 's', 'в' => 'd', 'а' => 'f', 'п' => 'g', 'р' => 'h',
        'о' => 'j', 'л' => 'k', 'д' => 'l', 'ж' => ';', 'э' => '\'',
        'я' => 'z', 'ч' => 'x', 'с' => 'c', 'м' => 'v', 'и' => 'b', 'т' => 'n',
        'ь' => 'm', 'б' => ',', 'ю' => '.',
        _ => lower,
    }
}

fn parse_args() -> Option<PathBuf> {
    let args: Vec<String> = std::env::args().collect();
    let mut i = 1;
    while i < args.len() {
        if args[i] == "--image" || args[i] == "-i" {
            if i + 1 < args.len() { return Some(PathBuf::from(&args[i + 1])); }
            eprintln!("[!] --image requires a file path");
            std::process::exit(1);
        }
        i += 1;
    }
    None
}

fn parse_target_count_arg() -> Option<usize> {
    let args: Vec<String> = std::env::args().collect();
    let mut i = 1;
    while i < args.len() {
        if args[i] == "--target" || args[i] == "-t" {
            if i + 1 < args.len() {
                if let Ok(n) = args[i + 1].parse::<usize>() { return Some(n); }
                eprintln!("[!] --target requires a number");
                std::process::exit(1);
            }
            eprintln!("[!] --target requires a value");
            std::process::exit(1);
        }
        i += 1;
    }
    None
}
```

```rust
impl AppState {
    pub fn new() -> Self { Self::default() }

    pub fn t(&self) -> &'static T { self.lang.t() }

    pub fn push_log(&mut self, line: impl Into<String>) {
        let line = line.into();
        let ts = timestamp();
        self.log.push(format!("{} {}", ts, line));
        if self.log.len() > 1000 {
            self.log.drain(0..self.log.len() - 1000);
        }
    }

    pub fn apply_device_event(&mut self, ev: DeviceEvent) {
        match ev {
            DeviceEvent::Arrived(info) => self.on_device_arrived(info),
            DeviceEvent::Removed { number, path } => {
                self.push_log(format!("[-] #{} {}", number, path));
                self.devices.remove(&number);
                self.recompute_status();
            }
        }
    }

    fn on_device_arrived(&mut self, info: DiskInfo) {
        let n = info.number;
        let gb = info.size_bytes as f64 / (1024.0 * 1024.0 * 1024.0);
        self.push_log(format!("[+] #{} {} ({:.2} GB) SN={}", n, info.product, gb, info.serial));
        self.devices.insert(n, DeviceSlot {
            info, status: SlotStatus::Waiting, progress: 0.0,
            bytes_written: 0, message: String::new(),
        });
        self.recompute_status();
    }

    fn recompute_status(&mut self) {
        if matches!(self.status, AppStatus::Running | AppStatus::Finished) { return; }
        let have = self.devices.len();
        let target = self.target_count;
        self.status = if have == 0 { AppStatus::Idle }
            else if have < target { AppStatus::WaitingForDevices }
            else { AppStatus::Ready };

        let mut sorted_numbers: Vec<u32> = self.devices.keys().copied().collect();
        sorted_numbers.sort_unstable();
        let ready_numbers: std::collections::BTreeSet<u32> =
            sorted_numbers.into_iter().take(target).collect();
        for (n, slot) in self.devices.iter_mut() {
            if matches!(slot.status, SlotStatus::Waiting | SlotStatus::Ready) {
                slot.status = if ready_numbers.contains(n) {
                    SlotStatus::Ready
                } else {
                    SlotStatus::Waiting
                };
            }
        }
    }

    pub fn ready_device_numbers(&self) -> Vec<u32> {
        let mut v: Vec<u32> = self.devices.iter()
            .filter(|(_, s)| s.status == SlotStatus::Ready)
            .map(|(n, _)| *n).collect();
        v.sort_unstable();
        v
    }

    pub fn ready_count(&self) -> usize {
        self.devices.values().filter(|s| s.status == SlotStatus::Ready).count()
    }

    pub fn active_or_ready_count(&self) -> usize {
        self.devices.values().filter(|s| matches!(s.status,
            SlotStatus::Ready | SlotStatus::Writing | SlotStatus::Verifying
            | SlotStatus::Formatting | SlotStatus::Done | SlotStatus::Failed)).count()
    }

    pub fn set_target_count(&mut self, n: usize) {
        self.target_count = n.clamp(TARGET_MIN, TARGET_MAX);
        self.recompute_status();
    }
    pub fn increase_target(&mut self) { self.set_target_count(self.target_count.saturating_add(1)); }
    pub fn decrease_target(&mut self) { self.set_target_count(self.target_count.saturating_sub(1)); }

    pub fn update_progress_by_index(&mut self, index: usize, bytes_written: u64, total: u64) {
        let Some((_, slot)) = self.devices.iter_mut().nth(index) else { return; };
        slot.bytes_written = bytes_written;
        slot.progress = if total > 0 {
            (bytes_written as f32 / total as f32).min(1.0)
        } else { 0.0 };
    }

    pub fn mark_completed_by_index(&mut self, index: usize) {
        let total = self.write_total_bytes;
        if let Some((_, slot)) = self.devices.iter_mut().nth(index) {
            slot.status = SlotStatus::Done;
            slot.progress = 1.0;
            slot.bytes_written = total.max(slot.bytes_written);
            slot.message.clear();
        }
    }

    pub fn mark_failed_by_index(&mut self, index: usize, message: String) {
        if let Some((_, slot)) = self.devices.iter_mut().nth(index) {
            slot.status = SlotStatus::Failed;
            slot.message = message;
        }
    }

    pub fn mark_slots_writing(&mut self, opened_numbers: &[u32]) {
        let opened: std::collections::BTreeSet<u32> = opened_numbers.iter().copied().collect();
        for (n, slot) in self.devices.iter_mut() {
            if opened.contains(n) {
                slot.status = SlotStatus::Writing;
                slot.progress = 0.0;
                slot.bytes_written = 0;
                slot.message.clear();
            } else if slot.status != SlotStatus::Failed {
                slot.status = SlotStatus::Failed;
                slot.message = "not opened for write".to_string();
            }
        }
    }

    pub fn rollback_slots_to_ready(&mut self) {
        for slot in self.devices.values_mut() {
            if slot.status != SlotStatus::Failed { slot.status = SlotStatus::Ready; }
        }
    }

    pub fn elapsed_secs(&self) -> Option<f64> {
        self.write_started_at.map(|t| t.elapsed().as_secs_f64())
    }

    fn active_slots(&self) -> Vec<&DeviceSlot> {
        self.devices.values()
            .filter(|s| matches!(s.status, SlotStatus::Writing | SlotStatus::Verifying))
            .collect()
    }

    pub fn average_bytes_written(&self) -> u64 {
        let active = self.active_slots();
        if active.is_empty() { return 0; }
        let sum: u64 = active.iter().map(|s| s.bytes_written).sum();
        sum / active.len() as u64
    }

    pub fn slowest_bytes_written(&self) -> u64 {
        self.active_slots().iter().map(|s| s.bytes_written).min().unwrap_or(0)
    }

    pub fn per_device_speed_mbps(&self) -> Option<f64> {
        let elapsed = self.elapsed_secs()?;
        if elapsed <= 0.5 { return None; }
        let avg = self.average_bytes_written();
        if avg == 0 { return None; }
        Some(avg as f64 / 1_048_576.0 / elapsed)
    }

    #[allow(dead_code)]
    pub fn total_bytes_written(&self) -> u64 {
        self.devices.values().map(|s| s.bytes_written).sum()
    }

    pub fn select_image_from_catalog(&mut self, index: usize) -> Result<(), String> {
        let entry = self.catalog.images.get(index)
            .ok_or_else(|| "index out of range".to_string())?.clone();
        if !entry.path.exists() {
            return Err(format!("file not found: {}", entry.path.display()));
        }
        self.image_path = Some(entry.path);
        self.image_size = entry.size_bytes;
        self.image_work_name = Some(entry.work_name);
        self.image_sha256 = Some(entry.sha256);
        self.image_hash_progress = None;
        self.hash_job = None;
        Ok(())
    }

    pub fn find_catalog_entry_by_path(&self, path: &std::path::Path)
        -> Option<&crate::catalog::ImageEntry> {
        self.catalog.images.iter().find(|e| e.path == path)
    }

    pub fn rename_in_catalog(&mut self, old_name: &str, new_name: &str) -> Result<(), String> {
        self.catalog.rename(old_name, new_name)?;
        if self.image_work_name.as_deref() == Some(old_name) {
            self.image_work_name = Some(new_name.to_string());
        }
        Ok(())
    }
}

fn timestamp() -> String {
    use std::time::{SystemTime, UNIX_EPOCH};
    let d = SystemTime::now().duration_since(UNIX_EPOCH).unwrap();
    format!("[{}s]", d.as_secs())
}
```

```rust
fn render_header(f: &mut Frame, state: &AppState, area: Rect) {
    let t = state.t();
    let (status_str, status_style) = match state.status {
        AppStatus::Idle => (t.status_idle, dim()),
        AppStatus::WaitingForDevices => (t.status_waiting, yellow()),
        AppStatus::Ready => (t.status_ready, green()),
        AppStatus::Running => (t.status_running, cyan()),
        AppStatus::Finished => (t.status_finished, magenta()),
    };

    let active_count = state.active_or_ready_count();
    let total_found = state.devices.len();
    let target = state.target_count;
    let target_style = if active_count >= target { green() } else { yellow() };
    let target_text = if total_found > target && state.status != AppStatus::Running {
        format!("{}/{}", active_count, target)
            + &t.target_extras_fmt.replace("{}", &total_found.to_string())
    } else {
        format!("{}/{}", active_count, target)
    };

    let line1 = Line::from(vec![
        label(t.lbl_status), Span::raw(" "),
        Span::styled(format!("{:<20}", status_str), bold(status_style)),
        label(t.lbl_target), Span::raw(" "),
        Span::styled(target_text, target_style),
        Span::styled(" [+/-]", dim()),

        .borders(Borders::ALL)

fn render_image_line(state: &AppState, area: Rect) -> Line<'static> {

fn render_hash_line(state: &AppState) -> Line<'static> {

fn render_timing_line(state: &AppState) -> Line<'static> {
    let t = state.t();

    Line::from(Span::styled(text, cyan()))
}

fn slot_status_display(state: &AppState, s: SlotStatus) -> (&'static str, Style) {
    let t = state.t();

fn slot_progress_display(slot: &crate::app::DeviceSlot) -> String {
    match slot.status {
        SlotStatus::Failed => {
            if slot.message.is_empty() { "FAIL".to_string() }
            else { truncate(&slot.message, 30) }
        }
        SlotStatus::Done => "100.0%".to_string(),
        SlotStatus::Writing | SlotStatus::Verifying | SlotStatus::Formatting => {
            format!("{:>5.1}%", slot.progress * 100.0)
        }
        _ => String::new(),
    }
}

fn render_import_status(state: &AppState, p: &ImportProgress) -> Line<'static> {
    let t = state.t();
    let tag = Span::styled("[import] ", yellow());
    match p {
        ImportProgress::Scanning { total } => Line::from(vec![
            tag, Span::raw(t.imp_scanning_fmt.replace("{}", &total.to_string()))]),
        ImportProgress::HashingFile { current, total, name, bytes_done, bytes_total } => {
            let pct = if *bytes_total > 0 {
                (*bytes_done as f64 / *bytes_total as f64) * 100.0
            } else { 0.0 };
            let prefix = t.imp_hashing_fmt
                .replace("{}", &current.to_string())
                .replacen("{}", &total.to_string(), 1);
            Line::from(vec![
                tag, Span::raw(format!("{} ", prefix)),
                Span::styled(name.clone(), cyan()),
                Span::raw(format!(" — {:.1}% ({:.0}/{:.0} MB)", pct,
                    *bytes_done as f64 / 1_048_576.0, *bytes_total as f64 / 1_048_576.0)),
            ])
        }
        ImportProgress::FileDone { name } => Line::from(vec![
            tag, Span::raw(format!("{} {}", t.imp_ready, name))]),
        ImportProgress::Done { imported, .. } => Line::from(vec![
            tag, Span::raw(t.imp_done_fmt.replace("{}", &imported.to_string()))]),
        ImportProgress::Error(e) => Line::from(vec![

fn truncate(s: &str, n: usize) -> String {
    if s.chars().count() <= n { s.to_string() }
    else {
        let t: String = s.chars().take(n.saturating_sub(1)).collect();
        format!("{}…", t)
    }
}

fn truncate_left(s: &str, n: usize) -> String {
    let count = s.chars().count();
    if count <= n { return s.to_string(); }
    if n <= 1 { return "…".to_string(); }
    let skip = count - (n - 1);
    let tail: String = s.chars().skip(skip).collect();
    format!("…{}", tail)
}

fn format_elapsed(secs: f64) -> String {
    let s = secs as u64;
    if s < 60 { format!("{}s", s) }
    else if s < 3600 { format!("{}m {:02}s", s / 60, s % 60) }
    else { format!("{}h {:02}m {:02}s", s / 3600, (s % 3600) / 60, s % 60) }
}
```

```rust
#[derive(Debug)]
pub enum HashProgress {
    Progress { bytes_done: u64, bytes_total: u64 },
    Done { size_bytes: u64, sha256: String },
    Error(String),
}

pub fn compute_sha256_async(path: String) -> Receiver<HashProgress> {
    let (tx, rx) = channel();
    thread::spawn(move || {
        if let Err(e) = compute_with_progress(&path, &tx) {
            let _ = tx.send(HashProgress::Error(e.to_string()));
        }
    });
    rx
}

fn compute_with_progress(path: &str, tx: &std::sync::mpsc::Sender<HashProgress>) -> io::Result<()> {
    let p = Path::new(path);
    let mut file = File::open(p)?;
    let size_bytes = file.metadata()?.len();
    let mut hasher = Sha256::new();
    let mut buf = vec![0u8; 4 * 1024 * 1024];
    let mut done: u64 = 0;
    let mut last_report = Instant::now();

    loop {
        let n = file.read(&mut buf)?;
        if n == 0 { break; }
        hasher.update(&buf[..n]);
        done += n as u64;
        if last_report.elapsed().as_millis() >= 200 {
            let _ = tx.send(HashProgress::Progress {
                bytes_done: done, bytes_total: size_bytes,
            });
            last_report = Instant::now();
        }
    }

    let digest = hasher.finalize();
    let sha256 = hex::encode(digest);
    let _ = tx.send(HashProgress::Done { size_bytes, sha256 });
    Ok(())
}
```

```rust
            Err(_) => Catalog::default(),
        }
    }
    pub fn save(&self, path: &Path) -> io::Result<()> {
        if let Some(parent) = path.parent() { fs::create_dir_all(parent)?; }
        let s = serde_json::to_string_pretty(self)

        fs::write(path, s)

    pub fn upsert(&mut self, entry: ImageEntry) {
        self.images.retain(|e| e.work_name != entry.work_name && e.path != entry.path);
        self.images.push(entry);
        self.images.sort_by(|a, b| a.work_name.cmp(&b.work_name));
    }
    pub fn remove_by_name(&mut self, work_name: &str) -> bool {
        let before = self.images.len();
        self.images.retain(|e| e.work_name != work_name);
        self.images.len() != before
    }
    pub fn rename(&mut self, old_name: &str, new_name: &str) -> Result<(), String> {
        if old_name == new_name { return Ok(()); }
        if self.images.iter().any(|e| e.work_name == new_name) {
            return Err(format!("имя '{}' уже занято", new_name));
        }
        let entry = self.images.iter_mut().find(|e| e.work_name == old_name)
            .ok_or_else(|| "образ не найден".to_string())?;
        entry.work_name = new_name.to_string();
        self.images.sort_by(|a, b| a.work_name.cmp(&b.work_name));

    }

#[derive(Debug, Clone)]
pub enum ImportProgress {
    Scanning { total: usize },
    HashingFile { current: usize, total: usize, name: String,
        bytes_done: u64, bytes_total: u64 },
    FileDone { name: String },
    Done { imported: usize, entries: Vec<ImageEntry> },

}

pub fn spawn_folder_import(folder: PathBuf) -> Receiver<ImportProgress> {
    let (tx, rx) = channel();
    std::thread::spawn(move || run_import(folder, tx));
    rx
}

fn run_import(folder: PathBuf, tx: std::sync::mpsc::Sender<ImportProgress>) {
    let send = |p: ImportProgress| { let _ = tx.send(p); };
    if !folder.is_dir() {
        send(ImportProgress::Error(format!("не директория: {}", folder.display())));
        return;
    }
    let files = collect_images(&folder);
    send(ImportProgress::Scanning { total: files.len() });
    if files.is_empty() {
        send(ImportProgress::Done { imported: 0, entries: Vec::new() });
        return;
    }
    let old = load_manifest(&folder);
    let mut by_rel: HashMap<String, ManifestEntry> = old.images.into_iter()
        .map(|e| (e.relative_path.clone(), e)).collect();
    let mut new_entries: Vec<ManifestEntry> = Vec::new();
    let mut entries: Vec<ImageEntry> = Vec::new();

    for (i, file) in files.iter().enumerate() {
        let Some(rel) = to_relative(&folder, file) else { continue; };
        let size = fs::metadata(file).map(|m| m.len()).unwrap_or(0);
        let (work_name, sha256) = match by_rel.remove(&rel) {
            Some(old) if old.size_bytes == size => (old.work_name, old.sha256),
            Some(old) => {
                let w = old.work_name;
                match hash_file(file, &tx, i + 1, files.len()) {
                    Ok(h) => (w, h),
                    Err(e) => { send(ImportProgress::Error(e)); return; }
                }
            }
            None => {
                let w = default_work_name(file);
                match hash_file(file, &tx, i + 1, files.len()) {
                    Ok(h) => (w, h),
                    Err(e) => { send(ImportProgress::Error(e)); return; }
                }
            }
        };
        let now = unix_now();
        new_entries.push(ManifestEntry {
            relative_path: rel, work_name: work_name.clone(),
            size_bytes: size, sha256: sha256.clone(), added_at_unix: now,
        });
        entries.push(ImageEntry {
            work_name: work_name.clone(), path: file.clone(),
            size_bytes: size, sha256, added_at_unix: now,
        });
        send(ImportProgress::FileDone { name: work_name });
    }
    let manifest = Manifest { version: MANIFEST_VERSION, images: new_entries };
    if let Err(e) = save_manifest(&folder, &manifest) {
        send(ImportProgress::Error(e.to_string()));
        return;
    }
    send(ImportProgress::Done { imported: entries.len(), entries });
}

fn hash_file(path: &Path, tx: &std::sync::mpsc::Sender<ImportProgress>,
    current: usize, total: usize) -> Result<String, String> {
    use sha2::{Digest, Sha256};
    use std::io::Read;
    let mut file = fs::File::open(path).map_err(|e| e.to_string())?;
    let size = file.metadata().map(|m| m.len()).unwrap_or(0);
    let mut hasher = Sha256::new();
    let mut buf = vec![0u8; 4 * 1024 * 1024];
    let mut done: u64 = 0;
    let mut last_report = Instant::now();
    let name = path.file_name().map(|s| s.to_string_lossy().to_string()).unwrap_or_default();
    loop {
        let n = file.read(&mut buf).map_err(|e| e.to_string())?;
        if n == 0 { break; }
        hasher.update(&buf[..n]);
        done += n as u64;
        if last_report.elapsed() >= Duration::from_millis(150) {
            let _ = tx.send(ImportProgress::HashingFile {
                current, total, name: name.clone(),
                bytes_done: done, bytes_total: size,
            });
            last_report = Instant::now();
        }
    }
    Ok(hex::encode(hasher.finalize()))
}

fn is_image_file(path: &Path) -> bool {
    match path.extension().and_then(|s| s.to_str()) {
        Some(ext) => matches!(ext.to_lowercase().as_str(), "img" | "iso" | "raw"),
        None => false,
    }
}

fn collect_images(root: &Path) -> Vec<PathBuf> {
    let mut out = Vec::new();
    collect_recursive(root, &mut out);
    out.sort();
    out
}

fn collect_recursive(dir: &Path, out: &mut Vec<PathBuf>) {
    let Ok(entries) = fs::read_dir(dir) else { return; };
    for entry in entries.flatten() {
        let path = entry.path();
        if path.is_dir() { collect_recursive(&path, out); }
        else if is_image_file(&path) { out.push(path); }
    }
}

fn manifest_path(folder: &Path) -> PathBuf { folder.join(MANIFEST_NAME) }

    match fs::read_to_string(&p) {
        Ok(s) => serde_json::from_str(&s).unwrap_or_default(),
        Err(_) => Manifest::default(),
    }
}

fn save_manifest(folder: &Path, manifest: &Manifest) -> io::Result<()> {
    let p = manifest_path(folder);
    let s = serde_json::to_string_pretty(manifest)
        .map_err(|e| io::Error::new(io::ErrorKind::Other, e))?;
    fs::write(p, s)
}

fn to_relative(folder: &Path, path: &Path) -> Option<String> {
    let rel = path.strip_prefix(folder).ok()?;
    let mut s = String::new();
    for (i, comp) in rel.components().enumerate() {
        if i > 0 { s.push('/'); }
        s.push_str(&comp.as_os_str().to_string_lossy());
    }
    Some(s)
}

    path.file_stem().map(|s| s.to_string_lossy().to_string())

}
```

```rust
use std::collections::HashMap;
use std::sync::mpsc::{channel, Receiver, Sender};
use std::thread;
use std::time::Duration;

use super::DiskInfo;

#[derive(Debug, Clone)]
pub enum DeviceEvent {
    Arrived(DiskInfo),
    Removed { number: u32, path: String },
}

#[derive(Debug, Clone, Default)]
pub struct DeviceFilter {
    pub usb_only: bool,
    pub min_size_bytes: u64,
    pub max_size_bytes: u64,
}

impl DeviceFilter {
    pub fn matches(&self, d: &DiskInfo) -> bool {
        if self.usb_only && !d.is_usb { return false; }
        if self.min_size_bytes > 0 && d.size_bytes < self.min_size_bytes { return false; }
        if self.max_size_bytes > 0 && d.size_bytes > self.max_size_bytes { return false; }
        true
    }
}

pub struct WatcherConfig {
    pub poll_interval: Duration,
    pub max_disks: u32,
    pub filter: DeviceFilter,
}

pub struct WatcherHandle {
    pub events: Receiver<DeviceEvent>,
}

pub fn spawn(config: WatcherConfig) -> WatcherHandle {
    let (tx, rx) = channel();
    thread::spawn(move || run_watcher(config, tx));
    WatcherHandle { events: rx }
}

fn run_watcher(config: WatcherConfig, tx: Sender<DeviceEvent>) {
    let mut known: HashMap<u32, DiskInfo> = HashMap::new();
    loop {
        let all = super::enumerate_disks(config.max_disks);
        let mut current: HashMap<u32, DiskInfo> = HashMap::new();
        for d in all {
            if config.filter.matches(&d) {
                current.insert(d.number, d);
            }
        }
        for (n, d) in &current {
            if !known.contains_key(n) {
                let _ = tx.send(DeviceEvent::Arrived(d.clone()));
            }
        }
        for (n, d) in &known {
            if !current.contains_key(n) {
                let _ = tx.send(DeviceEvent::Removed {
                    number: *n, path: d.path.clone(),
                });
            }
        }
        known = current;
        thread::sleep(config.poll_interval);
    }
}
```

```rust
    Completed { id: usize },
    Errored { id: usize, message: String },
    Finished { result: Result<(), String> },
}

const READ_BUFFER_BYTES: usize = 8 * 1024 * 1024;
const PROGRESS_STEP_BYTES: u64 = 512 * 1024;

pub fn start_write(
    image_path: String,
    mut destinations: Vec<File>,
    total_bytes: u64,
) -> Receiver<WriteEvent> {
    let (tx, rx) = channel();

    thread::spawn(move || {
        let image = match File::open(&image_path) {
            Ok(f) => f,
            Err(e) => {
                let _ = tx.send(WriteEvent::Finished {
                    result: Err(format!("Не удалось открыть образ: {}", e)),
                });
                return;
            }
        };
        let reader = io::BufReader::with_capacity(READ_BUFFER_BYTES, image);
        let tx_cb = tx.clone();
        let mut last_sent: Vec<u64> = vec![0; destinations.len()];

        let callback = move |msg: BusWriterMessage| match msg {
            BusWriterMessage::Written { id, bytes_written } => {
                if id < last_sent.len()
                    && bytes_written.saturating_sub(last_sent[id]) >= PROGRESS_STEP_BYTES
                {
                    last_sent[id] = bytes_written;
                    let _ = tx_cb.send(WriteEvent::Progress { id, bytes_written });
                }
            }
            BusWriterMessage::Completed { id } => {
                let _ = tx_cb.send(WriteEvent::Completed { id });
            }
            BusWriterMessage::Errored { id, why } => {
                let _ = tx_cb.send(WriteEvent::Errored { id, message: why.to_string() });
            }
        };

        let kill = || false;
        let result = BusWriter::new(reader, &mut destinations[..], callback, kill).write();
        let _ = tx.send(WriteEvent::Finished {
            result: result.map_err(|e| e.to_string()),
        });
        let _ = total_bytes;
    });

    rx
}
```

```rust
pub fn enumerate_disks(max: u32) -> Vec<DiskInfo> {
    let mut result = Vec::new();
    for n in 0..max {
        let file = match open_drive_read(n) {
            Ok(f) => f,
            Err(e) => {
                let code = e.raw_os_error().unwrap_or(0);
                if code == 5 {
                    result.push(DiskInfo {
                        number: n, path: format!(r"\\.\PhysicalDrive{}", n),
                        size_bytes: 0, is_usb: false, bus_type: -1,
                        vendor: String::new(), product: String::new(), serial: String::new(),
                    });
                }
                continue;
            }
        };
        let size_bytes = query_length(&file).unwrap_or(0);
        let (is_usb, bus_type, vendor, product, serial) =
            match query_device_descriptor(&file) {
                Ok(buf) => parse_descriptor(&buf),
                Err(_) => (false, 0, String::new(), String::new(), String::new()),
            };
        result.push(DiskInfo {
            number: n, path: format!(r"\\.\PhysicalDrive{}", n),
            size_bytes, is_usb, bus_type, vendor, product, serial,
        });
    }
    result
}

    let mut returned = 0u32;
    unsafe {
        DeviceIoControl(handle_of(file), IOCTL_DISK_GET_LENGTH_INFO,
            None, 0, Some(&mut info as *mut _ as *mut c_void),
            std::mem::size_of::<GET_LENGTH_INFORMATION>() as u32,
            Some(&mut returned), None,
        ).map_err(|e| io::Error::from_raw_os_error(e.code().0))?;
    }
    Ok(info.Length as u64)
}

fn query_device_descriptor(file: &File) -> io::Result<Vec<u8>> {
    let query = STORAGE_PROPERTY_QUERY {
        PropertyId: StorageDeviceProperty,
        QueryType: PropertyStandardQuery,
        AdditionalParameters: [0],
    };
    let mut buf = vec![0u8; 1024];
    let mut returned = 0u32;
    unsafe {
        DeviceIoControl(handle_of(file), IOCTL_STORAGE_QUERY_PROPERTY,
            Some(&query as *const _ as *const c_void),
            std::mem::size_of::<STORAGE_PROPERTY_QUERY>() as u32,
            Some(buf.as_mut_ptr() as *mut c_void), buf.len() as u32,
            Some(&mut returned), None,
        ).map_err(|e| io::Error::from_raw_os_error(e.code().0))?;
    }
    buf.truncate(returned as usize);
    Ok(buf)
}

fn read_cstr_at(buf: &[u8], offset: u32) -> String {
    if offset == 0 { return String::new(); }
    let start = offset as usize;
    if start >= buf.len() { return String::new(); }
    let end = buf[start..].iter().position(|&b| b == 0)
        .map(|i| start + i).unwrap_or(buf.len());
    String::from_utf8_lossy(&buf[start..end]).trim().to_string()
}

fn parse_descriptor(buf: &[u8]) -> (bool, i32, String, String, String) {
    use std::ptr;
    if buf.len() < std::mem::size_of::<STORAGE_DEVICE_DESCRIPTOR>() {
        return (false, 0, String::new(), String::new(), String::new());
    }
    let desc: STORAGE_DEVICE_DESCRIPTOR =
        unsafe { ptr::read_unaligned(buf.as_ptr() as *const STORAGE_DEVICE_DESCRIPTOR) };
    let is_usb = desc.BusType == BusTypeUsb;
    let bus_type = desc.BusType.0;
    let vendor = read_cstr_at(buf, desc.VendorIdOffset);
    let product = read_cstr_at(buf, desc.ProductIdOffset);
    let serial = read_cstr_at(buf, desc.SerialNumberOffset);
    (is_usb, bus_type, vendor, product, serial)
}
```

```rust
use std::ffi::CString;
use std::fs::{File, OpenOptions};
use std::io;
use std::os::unix::fs::OpenOptionsExt;
use std::os::unix::io::AsRawFd;
use std::path::Path;

#[derive(Debug, Clone)]
pub struct DiskInfo {
    pub number: u32,
    pub path: String,
    pub size_bytes: u64,
    pub is_usb: bool,
    pub bus_type: i32,
    pub vendor: String,
    pub product: String,
    pub serial: String,
}

pub fn enumerate_disks(_max: u32) -> Vec<DiskInfo> {
    let mut result = Vec::new();
    let sys_block = Path::new("/sys/block");
    let entries = match std::fs::read_dir(sys_block) {
        Ok(e) => e, Err(_) => return result,
    };
    for entry in entries.flatten() {
        let name = entry.file_name().to_string_lossy().to_string();
        if !name.starts_with("sd") { continue; }
        let removable_path = entry.path().join("removable");
        let removable = std::fs::read_to_string(&removable_path)
            .map(|s| s.trim() == "1").unwrap_or(false);
        if !removable { continue; }
        let size_path = entry.path().join("size");
        let size_sectors: u64 = std::fs::read_to_string(&size_path).ok()
            .and_then(|s| s.trim().parse().ok()).unwrap_or(0);
        let size_bytes = size_sectors * 512;
        let device_path = entry.path().join("device");
        let vendor = read_sys_attr(&device_path.join("vendor")).unwrap_or_default();
        let product = read_sys_attr(&device_path.join("model")).unwrap_or_default();
        let serial = read_sys_attr(&device_path.join("serial")).unwrap_or_default();
        let is_usb = check_usb_via_sysfs(&name);
        let number = if name.len() >= 3 {
            (name.as_bytes()[2] as u32).saturating_sub(b'a' as u32)
        } else { 0 };
        result.push(DiskInfo {
            number, path: format!("/dev/{}", name),
            size_bytes, is_usb,
            bus_type: if is_usb { 7 } else { 0 },
            vendor, product, serial,
        });
    }
    result.sort_by_key(|d| d.number);
    result
}

fn read_sys_attr(path: &Path) -> Option<String> {
    std::fs::read_to_string(path).ok()
        .map(|s| s.trim().to_string()).filter(|s| !s.is_empty())
}

fn check_usb_via_sysfs(block_name: &str) -> bool {
    let device_path = format!("/sys/block/{}/device", block_name);
    let real_path = match std::fs::canonicalize(&device_path) {
        Ok(p) => p, Err(_) => return false,
    };
    real_path.to_string_lossy().contains("usb")
}

pub fn unmount_all_volumes_on_disk(disk_number: u32) -> io::Result<usize> {
    let device_name = number_to_device_name(disk_number);
    let mut count = 0;
    for i in 1..=16 {
        let full_path = format!("{}", device_name) + &i.to_string();
        if !Path::new(&full_path).exists() { continue; }
        if unmount_path(&full_path).is_ok() { count += 1; }
    }
    if unmount_path(&device_name).is_ok() { count += 1; }
    if count > 0 { std::thread::sleep(std::time::Duration::from_millis(300)); }
    Ok(count)
}

fn number_to_device_name(number: u32) -> String {

    format!("/dev/sd{}", letter)
}

fn unmount_path(path: &str) -> io::Result<()> {
    let c_path = CString::new(path)
        .map_err(|_| io::Error::new(io::ErrorKind::InvalidInput, "bad path"))?;
    unsafe {
        let ret = libc::umount2(c_path.as_ptr(), 2);
        if ret != 0 { return Err(io::Error::last_os_error()); }
    }
    Ok(())
}

pub fn open_drive_write(disk_number: u32) -> io::Result<File> {
    let path = number_to_device_name(disk_number);
    OpenOptions::new()
        .write(true)
        .custom_flags(libc::O_SYNC)
        .open(&path)
}

pub fn open_drive_read(disk_number: u32) -> io::Result<File> {
    let path = number_to_device_name(disk_number);
    OpenOptions::new().read(true).open(&path)
}

pub fn update_disk_properties(file: &File) {
    unsafe { libc::ioctl(file.as_raw_fd(), 0x125f); }
}

pub fn flush_file(file: &File) -> io::Result<()> {
    file.sync_all()
}

pub fn set_current_thread_max_priority() -> io::Result<()> {
    unsafe {
        let param = libc::sched_param { sched_priority: 99 };
        let ret = libc::sched_setscheduler(0, libc::SCHED_FIFO, &param);
        if ret != 0 { return Err(io::Error::last_os_error()); }
    }
    Ok(())
}

pub fn set_disk_offline(_disk_number: u32, _offline: bool) -> io::Result<()> {
    Ok(())
}

pub fn is_admin() -> bool {
    unsafe { libc::geteuid() == 0 }
}

pub fn sync_all() {
    unsafe { libc::sync(); }
}
```

## Часть 6. Известные проблемы и что нужно сделать следующему агенту

### 🐛 Баги / ограничения

1. **Ошибка 433 (`ERROR_NO_SUCH_DEVICE`) на Windows** — возникает при записи на 2+ флешки через дешёвые кард-ридеры. Одна флешка перегревается и отваливается. **Решение:** реализовать последовательную запись (concurrency=1: сначала одна флешка, потом вторая).
2. **`O_DIRECT` не работает на Linux** — `bus_writer` использует невыровненные буферы. Используется `O_SYNC`, скорость на 10–15% ниже. Решение: переписать writer с `posix_memalign`-буферами и `pwrite`.
3. **Нет верификации после записи.** Нужно перечитывать флешку и сравнивать SHA-256 с образом.
4. **Нет форматирования.** Пользователь не может переинициализировать флешку в FAT32/exFAT/NTFS/ext4.
5. **Нет JSONL-логов** для аудита.
6. **`async_writer.rs` не реализован полностью** — экспериментальный код удалён, используется `bus_writer`.

### 🎯 Что нужно реализовать

- [ ] **GUI** (задача для следующего агента — можно на `egui`, `slint`, или Tauri).
- [ ] **Верификация** после записи (перечитать + SHA-256).
- [ ] **Форматирование** (`fmifs` на Windows, `mkfs.*` на Linux).
- [ ] **Последовательная запись** (`concurrency` в AppState, батчинг в `start_write_flow`).
- [ ] **JSONL-логи** (`flash_log.jsonl` для аудита).
- [ ] **`O_DIRECT`** на Linux с выровненными буферами (для максимальной скорости).
- [ ] **AppImage** для распространения на Linux.
- [ ] **Проверка `total_found > target`** — уже есть в UI (показывает «найдено N, лишние не трогаем»), но нужна в логике `recompute_status`.

### 🔧 Советы следующему агенту

- **Ключевой момент на Windows:** без `set_disk_offline` (IOCTL `DISK_ATTRIBUTE_OFFLINE`) запись на `PhysicalDriveN` даёт `ACCESS_DENIED`. **Не убирать.**
- **Ключевой момент на Linux:** `O_SYNC` вместо `O_DIRECT`. **Не менять** без переписывания writer.
- **`bus_writer`** — единственный проверенный движок. Если менять — сравнивать скорость на тестовой партии.
- **`FILE_FLAG_NO_BUFFERING`** на Windows требует размера буфера кратного 512. `bus_writer` использует 16 МБ — кратно.
- **Тестовый образ:** 3.93 ГБ `.img`. На одной флешке ~38.7 МБ/с (Windows USB 3.0). На двух одновременно — ~19 МБ/с на каждую + риск ошибки 433.
- **Флешки в тестах:** Generic STORAGE DEVICE 29.72 GB, серийники одинаковые (`000000001532`), идентификация по `PhysicalDriveN` (Win) / `/dev/sdX` (Linux).
